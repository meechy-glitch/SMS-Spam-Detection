# SMS Spam Detection Web App

A **Machine Learning–powered SMS Spam Detection web application** built with **Python, HuggingFace Transformers (DistilBERT), and FastAPI**.
It classifies SMS messages as **Spam** or **Not Spam** and returns a **confidence score** for each prediction.

---

## Features

- Fine-tuned **DistilBERT** model for high-accuracy text classification
- Confidence scores with per-class probability breakdown
- Clean Tailwind CSS frontend with animated result display
- Model persisted to disk — loads instantly on server start (no retraining)
- REST API with auto-generated docs at `/docs`
- PostgreSQL-ready for deployment (e.g. Render)

## Setup

### 1. Clone and install dependencies


### 2. Configure environment

Create a `.env` file in the project root:

```
DATABASE_URL=postgresql://user:password@localhost:5432/sms_spam
```

On Render, this is injected automatically when you attach a PostgreSQL database.

### 3. Train the model

```bash
python ml/train.py
```

This fine-tunes DistilBERT on `data/spam.csv`, prints evaluation metrics, and saves the model to `model/distilbert-spam/final/`.

### 4. Run the app

```bash
uvicorn main:app --reload
```

Open `http://127.0.0.1:8000` in your browser. Interactive API docs are available at `http://127.0.0.1:8000/docs`.

## API

**POST** `/predict`

```json
// Request
{ "smsInput": "Congratulations! You've won a free prize. Call now." }

// Response
{
  "result": "Spam",
  "confidence": 98.7,
  "spam_probability": 98.7,
  "ham_probability": 1.3
}
```

**GET** `/predictions`

Returns all past predictions from the database, newest first.

## Tech Stack

- **Model:** DistilBERT (`distilbert-base-uncased`) via HuggingFace Transformers
- **Backend:** FastAPI, Uvicorn, PyTorch, SQLAlchemy
- **Database:** PostgreSQL
- **Frontend:** HTML, Tailwind CSS
- **Data:** [SMS Spam Collection Dataset](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset)
